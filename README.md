# SoulBot

**v2.7.0** · Python / NoneBot2 / FastAPI / SQLite / 原生 WebUI

可配置人格、模拟情绪、好感度、长期记忆、自主社交与多模态 QQ 机器人。粉色渐变毛玻璃界面支持图片、GIF 和视频壁纸。人格与情绪属于软件模拟，不代表真实意识或主观情感。

## 启动

准备 Python **3.11–3.13**（推荐 3.11）和可访问外部服务的网络，下载项目：

```bash
git clone https://github.com/ikun441/Soulbot.git
cd Soulbot
./start.sh
```

Linux/macOS 在“终端”粘贴以上命令；如提示无执行权限，运行 `bash start.sh`。Windows 可下载仓库 ZIP、解压，安装 Python 时勾选“添加到 PATH”，然后双击 `start.cmd`。

启动脚本自动创建项目内 `.venv`，安装依赖并初始化数据，不全局安装 Python 包。终端显示 WebUI 地址，默认 <http://127.0.0.1:2526>。终端须保持运行，按 **Ctrl+C** 停止。

首次进入按中文向导创建管理员、配置 QQ 和模型。选配能力可跳过，普通用户无需编辑 YAML。端口如已修改，以启动输出为准。

首次向导提供 DeepSeek 官方注册、充值与 Key 配置入口，以及 ComfyUI 官方安装指引和真实连接探测；Emoji 为内置功能，可选初始化并创建分类。仪表盘卡片提供相关快捷操作。

插件市场从 `ikun441/soulbot_plugins` 的版本化索引读取条目；现已提供“第三方服务托管 v0.2.0”，支持官方服务下载、进度与取消、源码解压、配置引导和管理员启停管理。下载后默认关闭，管理员明确启用才加载 Python 代码。插件为受信任代码，不提供操作系统沙箱；密钥单独保存，不通过普通读取接口返回。

## 连接 QQ 与模型

1. 按 [NapCat 官方指南](https://napneko.github.io/guide/napcat) 安装并启动 NapCat，扫码登录机器人 QQ；SoulBot 不替代 QQ 客户端。
2. SoulBot 的“QQ 连接”选择**反向 WebSocket**，设置主人 QQ，启用 QQ 并保存。
3. 在 NapCat 网络设置添加 **WebSocket 客户端**，填入 SoulBot 页面显示的接收地址，默认 `ws://127.0.0.1:2526/onebot/v11/ws`。
4. 同机且仅监听回环地址时双方 Token 可留空；远程访问或监听 `0.0.0.0` 时双方必须配置相同 Token。
5. QQ/监听/接收路径修改后，停止并重启 SoulBot。检查 QQ 状态，再用页面的测试发送或向机器人私聊、群聊 @ 测试。
6. 在“AI 模型”填入服务商的 Base URL、Key 和模型 ID，保存并运行真实连接测试。模型列表从服务商读取，费用价格未知时显示“未知”。

需要机器人画图或发表情时，在“AI 模型”点击“验证并启用工具调用”，确认模型返回真实函数调用后再开启能力。测试会计入预算。生图页选择本地 ComfyUI、填写回环地址和已安装的 checkpoint，读取实际模型后保存；AI 只填写画面描述，工作流和参数由管理员控制。超过两句的 QQ 文字默认每两句发送一段，可在聊天行为设置中调整。

连接方向：`QQ → NapCat → OneBot V11 → SoulBot`。NapCat WebUI 端口、NapCat 正向 WS 服务端口、SoulBot 接收端口是不同概念，请按页面说明填写。

## 能力与管理入口

| 功能 | 管理页面与行为 |
| --- | --- |
| 人格、情绪、好感度 | 模板/导入导出/试聊、可编辑的全局五维状态机、按会话隔离关系 |
| 长期记忆 | 默认统一记忆库，私聊与群聊共同用于任务依据；模型可按管理员策略主动保存类型/重要性/可信度/有效期，支持关闭直接生效、删除及过期 |
| QQ 交流 | 被动/自然/活跃群聊、预过滤/聚合/冷却/免打扰，普通群消息不逐条调用模型 |
| 多模态 | Emoji、真实 meme-generator 及三个可选模板仓库、HTML 卡片、Edge/兼容 TTS、本地/兼容 ASR、云端 / 本地 ComfyUI 生图 |
| 搜索与探索 | 配置启用 JSON 的 SearXNG；公开主题探索默认关闭，只存本地记录 |
| 日记与周摘要 | 平台确认事实、当天预览、每周隔离汇总、独立模型润色及给主人待审批摘要 |
| 主动私聊 | 用户须私聊明确授权，管理员创建或启用 AI 生成草稿并审批任务，持久次数和冷却 |
| QQ 空间 | 草稿、可选审批、免审批自主发布和受众设置，至少间隔 72 小时、每 7 天最多 2 条 |
| 设置与动作记忆 | 默认在模型、工具和 QQ 发送前检索统一记忆；兼容局部模式；可选后台候选提取与情绪/好感度反馈 |
| 插件市场 | 文件夹插件、元数据与参数表单、下载校验、独立启停和工具权限；[开发规范](https://github.com/ikun441/soulbot_plugins/blob/main/PLUGIN_SPEC.md) |
| 系统与备份 | 暂停全部自主行为、下载私有 ZIP、上传校验并在下次启动恢复 |

搜索实例须启用 `search.formats: [html, json]`，在“搜索与探索”填地址。自建且无按次 API 费用时可显式填价格 `0`；价格未知时显示预警，继续调用。外部组件由用户按需启用；meme-generator、Chromium 和本地模型由项目隔离管理，不静默安装系统服务。

启用本地日记及模型工具能力后，可以在 QQ 中说“保存今天的日记”；模型调用 `create_diary`，只整理当前会话已确认的活动，事件不足会跳过。主人私聊可请求“把这段公开文字保存为空间草稿”，模型调用 `create_qzone_draft` 后可在 WebUI 查看；工具不直接发布，账号和受众沿用服务端配置。两项工具均可在“工具权限”关闭或设为审批。

Token 与费用预算只用于预警，不因超阈值或未知报价暂停调用；统计、估算和预警记录持续保留。模型实际上下文、回复长度、工具轮数、发送频率和用户授权分别管理。

记忆可以影响动作判断，不能覆盖权限、免打扰或发布边界。模型可主动新增和修改记忆；管理员开启自动保存时由服务端策略使新记忆生效，关闭时进入候选审核，模型不能自行更改授权策略。空间自主发布只有明确开启时执行，未知接口版本保留草稿，不确定结果不重发。

## 用户命令

- `/记住 内容`、`/记忆 开启`、`/记忆 关闭`、`/忘记我`。
- `/主动联系 允许`、`/主动联系 禁止`、`/免打扰 开启`、`/免打扰 关闭`，仅私聊可授权主动联系。
- `/日记 开启`、`/日记 关闭`、`/删除日记`。
- 主人/群管理员：`/soulbot 状态`、`/soulbot 静音 15`、`/soulbot 恢复`。

群聊记忆、日记等个人命令需 @机器人；明确的 meme 命令和已加载的模板关键词按独立命令路由处理。删除和关闭立即持久化，授权不由模型伪造。

## 账号、备份与更新

普通用户使用“登录账号”修改用户名及密码。忘记密码时停止 SoulBot，在 `.env` 设置 `SOULBOT_WEBUI_USERNAME` 与 `SOULBOT_WEBUI_PASSWORD` 后重启；新密码须 12–128 位，启动后自动转换为哈希。反代地址用 `SOULBOT_ONEBOT_REVERSE_WS_URL`，完整说明见 [排查与运维](docs/debug.md)。

更新前在“系统与备份”下载私有 ZIP，再停止 SoulBot：

```bash
git pull --ff-only
./start.sh
```

Windows 更新代码后再次双击 `start.cmd`。不要删除 `.env`、`config.yaml`、`data/`、`emoji/`。恢复备份需先上传校验，再停止并启动；会自动保存旧数据、退出旧会话并暂停自主行为。备份含密钥和私人记录，请勿公开分享。

新增频率设置位于“设置”和“聊天与权限”：被动回应概率/最短间隔、明确 @ 优先回应、自然/活跃群聊主动候选概率、主动间隔和每日上限；逐群设置留空继承全局，填写 0 可关闭对应概率。主动私聊继续使用独立授权和个人冷却。

QQ 中支持 `随机表情 @群友`、`/meme list 关键词`、`/meme info 模板ID或关键词`、`/meme preview 模板ID`、`/meme make 模板ID或关键词 @群友 "文字1" "文字2"`，以及“表情列表/表情详情/表情预览”中文别名。托管服务加载的中文模板关键词可直接使用。高级参数放在末尾，例如 `--args '{"字段":值}'`，实际字段以模板元数据为准。未启用服务时会给出配置入口，普通群消息不会因此逐条调用模型。

模型可在普通回复或获授权的主动群聊中自主选择 meme 模板并生成图片；`generate_meme` 的头像引用限 `avatar:bot`、`avatar:user`、`avatar:mentioned`，由服务端映射实际 QQ 上下文，不能指定任意网址。发送仍以 QQ 回执为准。


日记和 AI 空间草稿可随机采样统一记忆与仍保留的真实聊天，在“设置 → 日记与空间素材采样”调整数量、字符上限和近期窗口。日记仅把有日期证据的当日聊天作为当天经历；历史记忆只作回想。已归档日记默认限速生成 AI 表达，当前日记可手动润色；关闭 `diary.ai_expression` 后只保留原模板/人工表达。采样不另存聊天正文，也不自动发送日记。

- 第三方 GPU/推理依赖和模型的一键安装、通用服务自动守护、插件在线升级/依赖迁移/回滚。
- 操作系统级插件隔离、GitHub CI 正式启用、跨平台实机及长期稳定性验收、WebUI 一键更新回滚。

真实群聊多人连续互动、QQ 入站语音、独立云端服务和 Linux/Windows 实机仍需补齐对应环境下的验收；代码存在与真实环境验证分别记录。


QQ 收图理解在“AI 模型”页配置，默认关闭。先填写真实支持视觉的模型，使用“验证并启用图片理解”发送随机色块图验证，再开启“识别 QQ 收到的图片”。每轮默认最多3张，下载限制16MB，缩小并移除元数据后以低细节模式上传；动图仅第一帧，图片与下载链接不保存到聊天或审批记录。普通群聊图片仍先经过群权限、触发和冷却过滤。视觉请求只路由至声明支持视觉的服务；识别Token预估为每图2048，服务商返回真实用量后替换估算，价格未知不会显示为零。

全局关系升级会合并旧群聊/私聊记录：优先保留最近冻结记录的好感度，否则采用最近更新的分数，不累加好感；称呼取最近非空值，互动次数累加，当日已用增减额度累加，冷却取最近时间。任一旧记录冻结时合并后仍冻结。管理页可随时编辑统一关系；群名片仍按群显示。schema v19 不能由旧代码直接打开，回退须恢复升级前完整私有备份。


思考模型若在生成正文前耗尽输出额度，会明确返回“输出被截断”，不再误报响应格式不兼容，也不会执行不完整工具请求。AI 模型高级设置可分别配置主模型和备用模型的思考强度；默认不传参数、沿用服务商配置。仅选择服务商实际支持的取值。单次输出额度在“聊天与权限”的高级设置调整，推理也可能占用该额度。视觉、工具及连接测试不再额外压低到32/128 Token，但仍遵守实例单次输出上限。

主页和“关于 SoulBot”共享同一份能力清单：M0–M5 核心已实现，M6持续完善。点击阶段可直接打开相应页面；外部服务的可用性、历史实测与仍待验收范围分别展示。


搜索故障切换：在“搜索与探索 → 高级”配置最多两个独立 SearXNG 备用地址、价格及超时。主服务失败后按顺序尝试，每个地址一次；空结果不触发切换。所有尝试计入频率和用量，未知费用继续预警。下方可逐项测试已保存地址、查看当前配置的真实状态，在“Token 与费用”查看每次搜索记录。旧配置不自动启用备用服务；QQ工具自己的超时上限仍会约束整次调用。


语音与识别备用路由：在各工坊的“备用服务”中可分别设置最多两个独立服务、密钥、音色/模型、价格和超时。试听与转写可选择“自动”或指定一个服务；实际结果和费用记录标注使用的主/备用服务。ASR默认禁止云端备用上传，必须明确授权；本地Whisper备用需先手动准备模型，不会自动下载。每次实际尝试独立计次计费，超时或取消可能已计费；任务取消、配置/密钥变化及自主行为暂停会阻止后续切换。


发布新版本时更新版本常量后运行 `.venv/bin/python scripts/web_assets.py`，将原生模块依赖及页面资源同步为该版本。发布检查会拒绝未同步的资源；页面和静态文件要求浏览器重新验证，避免升级后继续显示旧控件。


生图备用设置位于“图片生成 → 备用生图服务”：各端点独立选择云端或ComfyUI，备用云端使用独立Key；ComfyUI仍只允许回环地址及固定工作流。结果不确定时默认不再生成第二张，需自行开启继续尝试；取消只停止等待并尝试删除本任务的排队项，不调用全局中断。生成记录显示实际服务和每个尝试的费用，自动空间配图共用此路由。手动输入的中文不会自动翻译；配置英文提示词的ComfyUI候选会指导聊天模型使用英文视觉描述。


非原生模型可在“AI 模型 → 高级兼容性”选择“JSON 兼容模式”，保存后点击“验证并启用工具调用”。验证包含只读请求与结果读取，两次模型调用可能计费；切换方式后需重新验证。备用模型独立选择调用方式。兼容模式不依赖服务商JSON专用参数，不能保证所有文本模型均能遵守；不完整、带围栏、含未知工具或无效参数的输出会明确拒绝，不执行本轮工具。普通试聊未提供工具时不解析聊天JSON。
