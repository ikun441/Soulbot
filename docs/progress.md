## 本次 v0.8.0

- 增加默认关闭的 ASR、本地 CPU Whisper 与独立兼容接口，WebUI 设置/模型准备/上传转写/取消。
- QQ 语音先权限与定向过滤，再去重/冷却；通过 NapCat WAV/Base64 获取，转写后重新检查授权。
- 持久识别次数与音频秒数，费用与 LLM/TTS 共用预算；识别文本不写入审计或用量表。
- 164 项测试通过；本地模型下载/加载、认证上传真实转写和进程清理通过。QQ/云端 Key、完整浏览器上传与跨平台部署仍需补验。

## 下一版 v0.9.0：云端图片生成

1. 增加独立 Image Generation Provider 与云端配置，保持与 HTML 排版能力分离。
2. WebUI 支持地址/密钥/模型/尺寸等能力声明、生成测试、私有预览和确认发送，不假设服务商支持所有参数。
3. generate_image 工具复用权限、任务调用次数和会话范围；拒绝模型指定任意文件或回传 URL 直接发送。
4. 明确每张图片报价与未知费用，跨 LLM/TTS/ASR 共享预算，并限制大小、并发、超时及重复计费。
5. 实际验证至少一条可用生图服务；依赖有效 Key 或平台能力的部分据实记录，并补齐 QQ 多模态链路验收。

M2 完成外部链路验收后进入 M3 人格/连续情绪/长期记忆。阶段未完成部分不会因出现页面或接口就计为完成。
