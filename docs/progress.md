## 本次 v0.9.0

- 实现独立云端生图接口、可选能力参数、独立密钥、WebUI 与 generate_image 工具。
- Base64 内容校验、私有产物和会话隔离，不自动下载 URL；发送前复核开关与权限。
- 持久生图次数/张数和共享费用预算，未知价格、取消/超时保持保守消耗。
- 195 项自动测试通过。真实验收脚本报告未配置，不将契约夹具作为云端出图证据；真实生图、QQ 和完整浏览器链路仍待验证。

## 本次 v0.9.1

- 生图页显示真实请求诊断：未启用、未配置、待测试、最近成功或最近失败。
- 只有真实生成请求更新诊断；地址、模型、返回能力参数或密钥改变后旧状态失效。诊断不会返回密钥、提示词或上游错误正文。
- 状态只保留在当前进程，重启后回到待测试；不会错误沿用旧进程的成功结果。
- 全套 196 项自动测试、Ruff、格式、语法、依赖和版本检查通过；使用本地契约夹具验证状态切换。
- 真实云端、QQ 与完整浏览器链路仍需凭据与服务完成验收。

## 本次 v0.9.2

- 提供受保护的 `/api/providers/status`，汇总 LLM、TTS、ASR 与生图状态。
- LLM 测试、语音合成与转写实际请求更新诊断；错误仅显示安全类别，密钥和内容不会进入状态记录。
- 按当前 Provider 配置及密钥摘要检查状态；配置变化、功能禁用、未配置和重启后不沿用旧结论。
- WebUI 在仪表盘、语音工坊和识别页展示状态，并区分云端付费请求与本地处理。
- 真实外部服务仍需用户配置凭据；NapCat/QQ 和完整浏览器链路未宣称验收。

## 本次 v0.9.3

- Provider API 把安全错误分类及可能计费标记交给 WebUI；不转发服务商原始错误正文。
- 模型、语音、识别和生图页面按错误类型显示排查步骤；网络/超时/取消/不确定格式提示先核对用量和账单。
- API 回归检查认证失败、服务端临时错误、关闭功能与可能计费状态；真实服务仍待凭据联调。

## 本次 v0.9.4：多模态验收清单

1. 首次配置向导汇总 SQLite、NoneBot/QQ 与 LLM/TTS/ASR/生图状态，并链接到逐项测试页面。
2. 状态汇总只读，不自动触发模型请求、云端媒体调用或 QQ 消息；明确单独测试的费用与录音上传边界。
3. 真实服务/QQ 端到端仍需凭据和已登录设备，不能把本地状态或契约测试当作验收完成。

## 下一版 v0.9.5：浏览器多模态验收

1. 对可在本机完成的卡片、TTS/ASR 本地流程做浏览器操作验收并修复问题。
2. 加强生成结果、试听/转写状态、取消和过期媒体的页面恢复体验。
3. 保持云端生图、兼容 API 与真实 QQ 的验证需要对应账户，按可用条件记录结果。
4. 若 M2 实际链路仍缺少外部凭据，继续明确待验收项，再进入 M3 人格、连续情绪与长期记忆。
