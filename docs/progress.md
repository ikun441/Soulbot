## 本次 v0.6.0

- 增加卡片工坊、三种固定模板与三种配色，真实 PNG 出图/预览/下载和受限 QQ 发送入口。
- 项目专用 Chromium 与校验中文字体，异步准备、实际启动检查、取消和失败提示。
- 结构化字段与正文转义，关闭网页脚本/网络，限制尺寸、任务数、并发和超时；子进程不继承机器人密钥。
- 独立 html_render 能力与 render_html 工具，产物按服务端会话隔离，复用权限、审计与发送前校验。
- 实际安装并验证中文、注入文字、三种模板、认证接口和工具调用；真实 QQ 回执仍待外部联调。

## 下一版 v0.7.0：TTS 语音表达

1. 定义音频结果结构：格式、MIME、采样率、声道及可用时长；语音与图片不混用类型。
2. 接入 Edge TTS（非官方方式）和 OpenAI 兼容语音接口，按服务能力区分音色/情绪参数，处理超时、限流和不可用。
3. WebUI 支持启停、实际音色列表、试听、连接测试与生成结果；可跳过配置，不使用假音频。
4. 增加 synthesize_speech 工具与 QQ record 消息发送，限定文本长度、调用次数、费用/频率和发送权限；产物继续按会话隔离。
5. 验证真实服务及音频格式、鉴权失败、取消/故障恢复和 QQ 回执。依赖有效账户的部分明确记录未联调状态。

TTS 后继续 ASR、云端生图与 M2 外部链路验收，再进入 M3。长期记忆、自主日记与空间不会仅因界面入口出现就宣称完成。
