## 本次 v0.7.0

- 语音工坊接入实际 Edge 音色/合成和独立兼容语音接口，提供设置、试听产物、下载与主人确认发送。
- 音频类型与图片分离，实际 MP3/PCM WAV 内容校验，文件私有保存，按服务端会话隔离并在 24 小时后过期。
- 持久字符/调用额度、共享费用预算、取消和中断记录；语音工具受权限与次数限制，发送前重新检查。
- 134 项测试通过；真实 Edge 322 音色、认证 API 和工具 MP3 合成通过。QQ 实机和云端 Key 尚未联调，浏览器完整试听因自动化超时待补验。

## 下一版 v0.8.0：ASR 语音转写

1. 定义 ASR Provider 和结构化转写结果，支持独立的兼容接口配置、密钥和能力声明。
2. QQ record 输入先过接入权限和群聊候选过滤，再按需获取受限音频和转写，避免逐条语音调用付费服务。
3. 限制录音大小、时长、下载地址与超时，不向模型开放任意文件/网址读取。
4. WebUI 提供音频上传、实际转写测试、独立开关和未知费用提示，语音转写费用纳入共享预算。
5. 验证真实服务、错误格式/密钥/限流、会话隐私与重启额度；需要凭据的链路据实报告未联调状态。

ASR 后继续云端生图与 M2 外部链路验收，再进入 M3。长期记忆、自主日记与空间不会仅因界面入口出现就宣称完成。
