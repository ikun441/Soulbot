# 云端图片生成 · v0.9.2

状态栏区分功能关闭、缺少配置、尚未测试、最近真实生成成功和最近真实生成失败。只有经过生图请求的结果才会作为测试状态；填写地址、模型与 Key 本身不表示服务可用。更改 Base URL、模型、尺寸、质量、返回格式、输出格式或密钥后，旧状态自动失效。测试时间与失败分类只保存在当前运行内存中，重启后重新显示“尚未测试”，不会保留上个进程的连接结论。

打开“云端生图”，填写独立 Base URL、模型 ID 和 API Key，按实际报价设置每张图片费用，然后启用并保存。输入提示词，点击“保存并生成一张图片”会真实请求服务，结果可私有预览、下载或确认后发送给主人。图片保留 24 小时，费用/审计不保存提示词或服务商改写的提示词。

当前已完成接口、故障处理与权限测试，**缺少有效生图凭据，尚未实际请求云端生成**。测试中的 PNG/HTTP 返回是明确的契约夹具，不是生图成功证据。真实 QQ 发送和完整浏览器生成流程也仍待联调。不要把“已填写配置”当成“服务已验证”。

## 服务与参数

依据 [官方 Images Generations API](https://developers.openai.com/api/reference/resources/images/methods/generate)，请求 POST `/images/generations`，基础字段为 model、prompt、n=1。独立密钥为 `SOULBOT_IMAGE_API_KEY`，不会沿用 LLM、TTS 或 ASR Key，也不会从普通配置接口回显。不预设模型列表，不以 HTML 排版替代云端自由生图。

可选参数默认不发送：size、quality、response_format、output_format。管理员按服务的实际能力选填，工具调用只能填写提示词，不能改变模型、价格或输出参数。尺寸可填 WIDTHxHEIGHT 或 auto，最多 1600 万像素。改变模型、尺寸或质量时需要重新核对报价。

部分模型默认返回 Base64 且不支持 response_format，另一些兼容服务需要显式选择 b64_json。因此默认不发送该字段。当前只接受一个 data 项里的 b64_json，严格解码并验证实际图片，最多 16MB；JSON 响应同样有上限。服务只返回 URL 时明确报错并保留可能费用，不自动下载、不跟随重定向，也不会把该 URL 交给 QQ 客户端读取。

不接受任意附加请求参数、文件路径或来自模型的下载地址。图片尺寸、类型以实际文件解析结果为准，不相信响应元数据或扩展名。

## 权限、额度与费用

- 默认关闭，最多 2 个并发任务；每次一张，默认每分钟 2 次、每日 10 张尝试额度，单次提示词 1000 字符、超时 120 秒。
- 次数与每日额度持久保存，失败尝试也占用次数和张数，重启不清零。每张报价按当前配置估算，无法确认时留空显示未知，不能误认为零费用。
- 生图与 LLM/TTS/ASR 共用每日人民币预算。存在未知费用时停止主动生图；未知费用也会影响其它主动模型任务。
- 取消、超时、中断或不完整成功响应可能已经计费，保留为“消耗未确认”；不自动重试可能计费的生成请求。
- generate_image 每次模型任务最多一次，继续遵守全部工具总调用上限；产物作用域由服务端注入，私聊和群之间不能交叉读取。
- 图片发送前再次检查 QQ 会话权限、生图开关和工具权限，包括等待全局发送间隔之后。通用图片发送 API 也按图片来源执行同一检查；关闭生图后不能绕过它发送生图产物。
- 主人测试发送需确认，每分钟最多一次，收到了实际 OneBot message_id 才报告平台确认。当前真实 QQ 接收仍未验证。

## 实际验收与升级

在 WebUI 中配置并启用后，可执行 `PYTHONPATH=. .venv/bin/python scripts/verify_image.py`。它会真实生成一张通用水彩温室图，可能计费，使用项目正式共享预算并保留私有图片，不发送 QQ。缺少配置时只报告 not_run，不生成替代图。验收输出写到忽略的 output/image-live，不包含密钥和提示词历史。

本版新增 SQLite schema 6→7 的 image_usage 表，保留管理员、会话和已有用量。升级前备份 `.env`、`config.yaml` 和 `data`；旧版不能直接打开 schema 7，回退需要恢复升级前数据库备份。没有增加 Python 或前端依赖。
