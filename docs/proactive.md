# 主动联系与调度 · v0.9.8

本版交付 M4 的授权和调度基础：用户从 QQ 私聊授权，管理员整理并审批固定文本草稿，后台在有限时间窗口中发送。默认关闭主动私聊发送；授权本身不会生成任务。AI 自主选题、生成草稿、日记及周记仍在后续阶段。

## 用户授权与拒绝

向机器人私聊发送：

- `/主动联系 允许`：允许当前机器人主动私聊当前用户。
- `/主动联系 禁止`：撤销授权，并取消该机器人与用户所有待审批、已安排和条件等待任务。
- `/免打扰 开启`：暂停主动联系，普通私聊回复保持原规则。
- `/免打扰 关闭`：解除用户主动联系暂停，仍需授权、管理许可和时段条件。

群聊和语音转写不能授予此授权。不同机器人对同一用户独立记录。撤销与开启免打扰即使处于回复冷却，也会先保存偏好；确认消息可能因冷却被省略。已进入平台的发送无法撤回。

管理端能停用联系人、设置附加免打扰时段，但不能授予用户授权，也不能解除用户设置的暂停。只有真实私聊命令进入授权处理；模型没有创建授权或审批的工具。

## 使用管理页

1. 用户授权后，在“主动联系与调度”查找对应机器人和用户。
2. 点击“安排草稿”，填写消息正文及最早/最晚发送时间。创建时最多向未来安排 7 天，窗口长度为 10 秒到 7 天。
3. 保存到待审批队列，核对正文、目标和时间后单独审批。正文与收件人保存后固定，修改需取消并重建。审批不绕过用户拒绝。
4. 明确启用“已审批的主动私聊发送”。每次从关闭变成开启都有确认，随后后台会发送满足全部条件的已审批任务。
5. 查看任务原因和状态轨迹。取消只对未执行任务有效，过期不补发。

草稿创建带有持久请求 ID。同一请求的重复提交返回原任务，改变载荷则拒绝，避免网络重试创建重复任务。队列最多同时保留 200 个未结束任务；后台每轮最多检查 20 个到期任务，按下次检查时间排序避免前面的受阻任务长期挡住后面的任务。

## 发送条件与持久限额

检查项包括全局开关、QQ/私聊接入、用户授权、用户暂停、管理员停用、忽略名单、免打扰时段、对应 QQ 在线、时间窗口、冷却、每日额度及现有 Token/费用预算。任何未知费用也会暂停这种可选行为。固定文本发送不调用 LLM、不新增模型 Token 或生成费用。

- 默认每个机器人/用户每天最多 1 次，全局主动私聊每天最多 10 次。
- 默认同一机器人/用户最短间隔 1440 分钟，跨午夜不会清空经过时间限制。
- 默认窗口内随机延迟最多 120 秒，创建时选择并持久化，重启不重新抽取。
- 默认每 30 秒检查条件。没有满足条件时继续等待，直到窗口结束。
- 管理端联系人时段默认 00:00—08:00，使用系统配置时区；支持跨午夜，相同时间表示全天免打扰。原有全局夜间免打扰同时生效。

每日计数包含已预留但未确认的尝试，SQLite 事务保证多个任务/进程不会同时超过限额。该限额只管理本版主动私聊队列；已有自然群聊策略仍使用自己的授权与额度。私聊任务在全局发送间隔等待后再次复核审批、用户授权、暂停、时段、窗口、预算和限额。统计日变化后不会使用上一日的在途预留发送。

## 状态与故障恢复

状态依次可为待审批、已安排、条件等待、执行中，最终为平台确认发送、发送未确认、已取消、已拒绝或已过期。页面显示具体等待原因和最近 20 条状态轨迹；完整轨迹保存在数据库。

执行前持久化预留和执行状态，收到平台有效回执才标记发送成功。超时、异常、取消运行或关机中断标记为发送未确认，保留额度，不自动重试。硬中断后，超过 90 秒执行租期的任务转为未确认并停止重放。后台单轮发送有 30 秒上限；NoneBot 发送本身另有 10 秒超时。

用户撤销会取消尚未开始的任务，在途任务在下一次权限复核时阻止发送；已经交给平台的消息可能无法撤回。需要手动重建未确认任务前，先检查实际 QQ 历史，避免人工重复发送。

## 配置、隐私与升级

`proactive` 使用与 WebUI 相同的 Pydantic Schema，包含 enabled、evaluation_interval_seconds、max_per_user_day、max_daily_total、min_interval_minutes、jitter_max_seconds。设置可以热更新，不会清零当日预留。

管理 API 均要求管理员登录，写请求同时验证来源。联系人修改不接受 opted_in/user_paused 等用户字段，创建草稿不能指定审批人或最终状态。审计只记录动作和固定状态，不记录消息正文或收件人；运行数据不进入普通配置导出。

升级前停止服务并备份 config.yaml、.env 和 data。schema v9→v10 追加授权、任务、用量和轨迹表，保留账号、情绪、好感度、记忆与已有用量。回退需恢复兼容数据库备份。

专项测试：`.venv/bin/python -m pytest -q tests/test_proactive.py`。模拟发送器用于验证权限、竞态、并发限额及中断；隔离浏览器验证真实后端审批及队列，不代表向真实 QQ 用户主动发送已经验收。
