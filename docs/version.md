# SoulBot 版本更新日志

## v0.5.0 - 2026-10-25

### 新增
- `.env` 读取、保存并应用 WebUI 管理账号和密码哈希；首次向导创建与账号修改均同步保存，已有 SQLite 账号自动补存，密码不变时保留会话。
- 可通过 `SOULBOT_WEBUI_PASSWORD` 预设或恢复密码；启动后转换成随机盐 PBKDF2 哈希并删除明文行。账号实际变化时撤销旧会话。
- 原生“登录账号”页及受保护的账号 API，修改需校验当前密码，当前设备获得新会话。
- QQ 页编辑反向/反代 WS 地址并保存到 `SOULBOT_ONEBOT_REVERSE_WS_URL`；重启应用地址和自定义接收路径，继续执行 OneBot Token 和启用状态检查。
- 进程环境优先于 `.env`；受进程变量管理的字段阻止 WebUI 覆盖。`.env` 原子写入并保留其他配置，POSIX 文件权限为 0600。

### 验证
- 新增 20 项验证覆盖账号迁移、启动导入/恢复、密码字面值、哈希脱敏、优先级、会话撤销和反向地址校验/保存/恢复。
- 隔离子进程启动真实 NoneBot，通过自定义 WS 路径完成 get_status；错误 Token 及停用后的连接均被拒绝，不代表真实 QQ 登录验收。
- 全套 96 项回归通过；Ruff、前端/启动脚本语法及依赖一致性检查通过。

### 升级说明与已知问题
- 无数据库 Schema 变化；首次启动会把旧管理员用户名和哈希补存进项目 `.env`，不会重置密码。更新前应备份 `.env`、config.yaml、data/ 和 emoji/。
- 修改 `.env` 或反向 WS 路径需要重启；WebUI 修改账号立即生效。自定义 URL 不会自动配置监听、TLS 或反向代理，跨机器网络需单独设置。
- 密码恢复步骤见 docs/environment.md。TTS/ASR、HTML Render、云端生图和长期记忆继续按后续阶段推进。

## v0.4.0 - 2026-10-25

### 新增
- WebUI 可选下载/启用 MemeCrafters/meme-generator-contrib、anyliew/meme_emoji 与 LRZ9712/tudou-meme；固定到已验证提交并校验 SHA-256，展示许可证、加载冲突和导入错误。
- 每个扩展可独立禁用模板 ID、配置每分钟生成上限；全局与逐仓库共享持久滚动限额，覆盖预览与生成。
- 扩展 ZIP 限制路径、符号链接、文件数及解压大小；原子安装保留旧版本。模板只在独立 meme-generator 进程加载，默认不启用。

### 验证
- 实际下载/加载三仓库共 857 个模板（13/430/119）；4 个同名冲突被保留并展示，零导入错误；各仓库真实生成 JPEG/GIF。
- 扩展自动化覆盖压缩包安全、快照校验/旧版本保留、配置边界、认证 API、审计、并发安全基础和跨重启限额；全套 76 项测试通过。
- Ruff、JavaScript 语法、启动脚本语法和 pip check 通过。

### 已知问题
- HTML Render、TTS/ASR、云端生图、NapCat/QQ 实机及真实 LLM Tool Calling 尚未交付/联调，继续按 M2 范围推进。
- 扩展仓库的 Python 模板代码会在 meme-generator 专用虚拟环境中执行；默认关闭，固定快照和哈希校验不等同于操作系统沙箱。
- 第三方模板素材的授权/说明以各自仓库为准；扩展安装需要数百 MB 磁盘空间和网络。

## v0.3.0 - 2026-10-25

### 新增
- M2 第一个增量：本地 Emoji 中文递归索引、标签/别名、模糊检索、分页、上传与私有预览。
- meme-generator 0.1.14 自动安装到独立环境，准备并校验官方素材和中文字体；后台状态、单实例锁、有限重启、优雅停止与外部服务模式。
- 实际模板列表、元数据、预览与 multipart 生成，按模板校验图片/文字数量和高级参数，结果附格式/尺寸/大小。
- 原生 WebUI 表情库、表情包工坊和工具权限页；受限的给主人 QQ 图片测试发送入口。
- QQ 媒体工具调用最多 5 次、4 轮模型请求与 2 张图片；每次工具参数校验，发送前重新检查权限。工具 Schema 计入输入和任务预算。

### 验证
- 真实安装验证了 2,869 个官方素材；读取到 295 个模板；JPEG、GIF、预览、重复实例拒绝及子进程异常恢复均通过。
- QQ 实际图片回执仍需用户已登录的 NapCat，外部 LLM 的真实 Tool Calling 仍待有效账户联调。

### 升级说明与已知问题
- SQLite 自动升级至 schema v4，保留账户/用量/上下文，增加媒体会话隔离；更新前停止并备份 data、config.yaml、.env 和 emoji。
- meme 默认未启用。首次安装会下载依赖和素材，过程不会阻塞管理端；运行文件不纳入 Git。
- meme 原生依赖本次验证环境为 macOS arm64 / Python 3.11；Linux/Windows 和其它 Python 版本仍需实机验证。
- TTS、ASR、云端生图、HTML Render、QQ 来图理解和长期记忆尚未在本次增量交付；M2 继续推进。
- 生成图片默认 24 小时过期，下次生成或程序启动时清理；Emoji 文件长期保存在本地库。

## v0.2.0 - 2026-10-25

### 新增
- OpenAI 兼容 Chat Completions Provider：真实模型列表、用量解析、可选 SSE 流式输出、有限重试与备用服务。
- 持久 Token/费用预留与用量账本，未知费用明确显示；超预算时拒绝新调用。
- OneBot V11 消息归一化、私聊回复、群聊唤醒/连续对话/冷却/消息聚合及管理员静默命令。
- 原生 WebUI 的 AI 连接测试、带预算的网页试聊、行为权限、用量查看和短期上下文清理。
- 配置 Schema 与 SQLite 从 M0 兼容迁移至 schema v2；QQ 页面增加向主人发送测试消息入口。

### 修复
- 识别模型用量缺失、流式中断、请求拒绝与不确定结果，避免把未知成本记作零。
- 通过服务端授权和持久额度检查限制群聊决策、测试发送和重复事件。

### 兼容性
- 配置与数据库可从 v0.1.0 自动向前迁移；恢复旧程序前请备份数据。
- 外部 QQ/LLM 仍需用户自行配置；本地协议测试不代表 NapCat 或模型商实际端到端验证。

### 已知问题
- 本版本只接收 OneBot V11 文本；图片、语音、记忆、情绪、日记、meme-generator 与 QQ 空间功能尚未交付。
- 网页试聊的上下文只保留在当前浏览器会话；QQ 短期上下文按群/用户隔离保存。
- 实际 LLM 价格需用户填写。未填写时仅显示未知费用并使用保守 Token 预留。

## v0.1.0 - 2026-10-24

### 新增
- M0 模块化项目、实施计划与分阶段验收清单。
- `.venv` 自动管理、start.sh、start.cmd 与简体中文 start.md。
- FastAPI、NoneBot2 驱动与 OneBot V11 初始化，默认关闭 QQ 接入。
- Pydantic 统一配置、SQLite、管理员哈希密码/会话、向导进度与操作记录。
- 配置原子保存、上一版恢复、密钥独立存储和脱敏导出。
- 八步首次配置向导与本机 OneBot 只读协议探测。
- 粉色渐变毛玻璃原生 WebUI、响应式布局、自定义图片/GIF/视频壁纸与动态开关。
- Provider Registry、Tool Registry 和默认拒绝权限基础。

### 优化
- 增加页面方向过渡、卡片错峰入场、滚动显现、侧栏滑动指示、按钮涟漪/加载反馈、开关回弹、通知/弹窗和壁纸渐变。
- 动态关闭与系统减少动态效果会停止界面动画；快速切换取消旧过渡，保持表单可操作。
- 普通配置无需手工修改 YAML；错误不会回显敏感输入。
- 未实现能力明确标示所属阶段，不展示伪造的服务成功结果。

### 兼容性变化
- 初始版本，无历史配置迁移。运行要求 Python 3.11–3.13；包版本按 PEP 440 为 0.1.0，UI 和 Git Tag 为 v0.1.0。

### 已知问题
- 尚不支持 AI/QQ 聊天；M1 开放真实 Provider 与消息处理。
- TTS/ASR、生图、meme-generator、HTML Render、记忆/情绪、日记、自主行为和 QZone 仍按 M2–M5 计划实现。
- NapCat/LLM 无实际可用登录/凭据时不能做端到端验收；协议检测失败会据实提示。
- Windows/Linux 启动需对应系统实测；当前验证环境为 macOS / Python 3.11。
- 当前 Token 缺少 workflow 权限，GitHub Actions 未启用；CI 配置保留为 docs/ci.yml.example。
- 视频兼容性取决于浏览器编码支持；M0 无完整管理员密码重置流程。

### 升级说明
- 首次运行自动生成 config.yaml 与 data，请勿提交这些文件。
- 更新前停止服务并备份 config.yaml、data/、.env 和 emoji/。
