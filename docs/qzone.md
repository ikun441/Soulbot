# QQ 空间与自主发布 · v2.0.0

WebUI「QQ 空间」提供公开主题草稿、可选审批及自主发布。新安装默认关闭发布，默认要求审批；按用户追加需求支持无需逐条审批。

## 配置无需审批的自主发布

1. 设置好主人 QQ，连接真实 NapCat，配置并测试 LLM。
2. 在空间规则中启用「空间发布」，关闭「要求逐条人工审批」，开启「自主生成并发布」。
3. 填写自主发布机器人的 QQ（不是主人 QQ），选择受众，填写公开主题（每行一个）。保存并确认该模式。
4. 系统约每 10—11 分钟评估一次。目标账号在线、接口版本已核实、非免打扰时段、预算/频率允许后，按公开主题起草，检查隐私并直接发布，不再弹出逐条审批。

自动起草只发送配置的公开主题，不导入私聊、长期记忆、日记或私有人格 Prompt，不声称发生过实际经历。只对后台自己生成的自主草稿执行自动发布，不扫描并自动发布管理员保存的其它草稿。修改账号、受众、主题、审批模式、主人或总开关后，本轮草稿保留，发送前重新检查权限；不伪造人工审批字段。

模型调用计入 Token 和费用。价格未配置或当日存在未知费用时暂停自主起草，状态页显示原因；不能以零费用代替未知。测试实例使用官方峰值未命中缓存价格保守估算，非账单结算：参见 [DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，核实于 2026-10-27。默认免打扰 00:00—08:00 遵循系统时区。

```yaml
qzone:
  enabled: false
  require_approval: true
  autonomous_enabled: false
  auto_bot_id: ""
  auto_audience: friends  # friends / self / public
  auto_topics:
    - 阳光与好心情
    - 音乐与平凡生活里的小美好
  min_interval_hours: 72
  max_posts_per_week: 2
```

自主发布须 require_approval=false，并配置 auto_bot_id。总开关关闭会停止所有空间发布，保留已有记录和消耗。自主开关关闭只停止后台起草与发布；手动发布继续服从总开关和审批模式。

## 手动草稿与可选审批

可以离线准备草稿，手写正文或选择 AI 根据公开主题起草。AI 请求计入预算，每分钟最多一次。保存后可编辑正文/受众，查看隐私提示及轨迹。免审批模式下可直接手动发布，界面仍确认账号、正文和受众。

审批模式下需管理员逐字核对并勾选公开声明，确认完整正文后通过。审批绑定账号、正文、受众和配置主人，24 小时有效，修改即失效；审批本身不发送动态。模型无法伪造审批。拒绝和撤销可停止尚未执行的草稿。

隐私启发式规则会阻止疑似账号/长数字、邮箱、密钥、私人来源标记、带凭据或本机地址的链接。两种模式均不能绕过，规则无法识别所有私人信息，不要把私密资料填入公开主题。

## 已核实的平台契约

核实日期 2026-10-27，支持 NapCat **v4.18.38**：

- [发布实现](https://github.com/NapNeko/NapCatQQ/blob/v4.18.38/packages/napcat-onebot/action/extends/SendQzoneMsg.ts)
- [注册入口](https://github.com/NapNeko/NapCatQQ/blob/v4.18.38/packages/napcat-onebot/action/index.ts)
- [版本接口](https://github.com/NapNeko/NapCatQQ/blob/v4.18.38/packages/napcat-onebot/action/system/GetVersionInfo.ts)

只读 get_version_info / get_status / get_login_info 核对版本、QQ 在线及身份，不取 cookies，不调用空白发布探测。版本契约已核实不保证平台一定允许发布。未知版本或未连接禁用发布，保留草稿。

实际使用原生 send_qzone_msg，纯文字 content、空 images、ugc_right=4（好友）/64（自己）/1（所有人），只有合法非空 tid 才显示「平台已确认」。发布前复核同一 Bot 对象。未将空友爱看的独立能力接口误作发说说权限。

真实验证：NoneBot/NapCat 在线和身份、主人消息平台回执、DeepSeek 草稿通过；按用户追加授权启用免审批自主模式，后台自行起草、检查并发送仅自己可见动态，平台返回有效 tid，approved_at 保持空。好友/所有人受众及附图尚未实测。

## 限额、异常与恢复

所有机器人共用至少 72 小时间隔，滚动 7 天最多 2 次。可以增大间隔或把上限降到 1；SQLite 请求前事务预留，不因时区或重启重置。

发布最长等待 30 秒。超时、取消、异常或无合法回执标为结果不确定并保留额度，不重发；中断租约 90 秒后恢复不确定。请到 QQ 空间人工核对，该草稿不能再次发布。重新生成也不能绕过全局额度，无清空消耗接口。

后台调度有持久检查时间和 180 秒单执行租约，旧任务不能释放新任务租约。AI 中断 120 秒后显示未完成；同一请求标识不重复生成。结果不确定时不会启动无限补发。

暂不支持附图、从私人日记生成公开内容、空间评论或好友操作。不要覆盖其它程序占用的端口或网络配置。
